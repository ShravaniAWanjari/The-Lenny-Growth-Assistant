# Markdown Artifact Skill

## Purpose
Produce standalone, formatted Markdown documents synthesizing Lenny's Podcast insights for export, note-taking, or knowledge base storage.

## Requirements
- Valid, standard GitHub-flavored Markdown.
- Proper hierarchical heading structure (`# Title`, `## Sections`, `### Subsections`).
- Tables for comparisons or structured data where helpful.
- Blockquotes for direct memorable guest quotes.
- Footnotes or source reference section at the bottom linking to timestamped episodes.
